# Meeting Agenda Generator

## Category
Productivity

## Description
Creates structured, efficient meeting agendas with clear objectives, time allocations, and action items to ensure productive meetings.

## Prompt
```
Create a professional meeting agenda for the following meeting:

Meeting Type: [e.g., Team Standup, Project Kickoff, Client Review]
Duration: [e.g., 30 minutes, 1 hour]
Participants: [List key participants]
Main Objective: [What should be accomplished]

Topics to cover:
1. [Topic 1]
2. [Topic 2]
3. [Topic 3]

Please include:
- Time allocation for each topic
- Clear objectives
- Discussion points
- Space for action items
- Parking lot for off-topic items
```

## Usage Guide
1. Define your meeting type and duration
2. List all participants and their roles
3. Specify the main objective clearly
4. List topics in order of importance
5. Share the agenda 24 hours before the meeting

## Example Output
You'll receive a structured agenda with time-boxed sections, clear objectives, and a format ready to share with participants.

## Tips
- Always allocate time for questions
- Include a "decisions needed" section
- Leave buffer time for overruns
- Add pre-meeting preparation items
- Follow up with action items after the meeting
