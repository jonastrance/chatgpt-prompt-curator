# Dialogue Enhancement Coach

## Category
Creative Writing

## Description
Improves dialogue writing with techniques for natural conversation, character voice distinction, subtext, and emotional resonance.

## Prompt
```
Analyze and improve the following dialogue:

Scene Context: [Where/when this conversation happens]
Characters Involved: [Names and brief descriptions]
Scene Purpose: [What this dialogue needs to accomplish]
Emotional Tone: [e.g., Tense, Playful, Sad, Confrontational]

Current Dialogue:
[Paste your dialogue here]

Please provide:

1. ANALYSIS OF CURRENT DIALOGUE
   - What works well
   - What feels unnatural or wooden
   - Pacing issues
   - Character voice consistency
   - Missing subtext or emotion

2. IMPROVED VERSION
   - Rewritten dialogue with enhancements
   - More natural speech patterns
   - Distinct voices for each character
   - Added subtext where appropriate
   - Better rhythm and pacing

3. TECHNIQUE BREAKDOWN
   - Subtext techniques used
   - How character voice was differentiated
   - Use of dialogue tags and action beats
   - Pacing decisions
   - Emotional layering

4. DIALOGUE WRITING TIPS
   - Specific advice for this scene
   - Common mistakes to avoid
   - How to show character through dialogue
   - When to use/skip dialogue tags

5. ALTERNATIVE APPROACHES
   - Different ways to achieve same goals
   - Options for more/less subtle
   - Variations in tone or approach

Also consider:
- Real speech patterns (interruptions, fragments, pauses)
- What characters DON'T say (subtext)
- Body language and action beats
- Each character's unique voice
- Conflict and tension
- Revelation of information
- Forward movement of plot/character
```

## Usage Guide
1. Write your first draft dialogue
2. Provide full scene context
3. Review the analysis carefully
4. Compare original with improved version
5. Apply techniques to other scenes
6. Read dialogue aloud to test naturalness
7. Ensure each character sounds distinct

## Example Output
Detailed dialogue analysis with improved version, technique explanations, and specific writing advice for natural, compelling conversations.

## Tips
- Read dialogue aloud always
- People rarely say exactly what they mean
- Use subtext for depth
- Action beats > dialogue tags
- Each character needs distinct voice
- Vary sentence length and structure
- Conflict creates interesting dialogue
- Less is often more
- Use silence and pauses
- Avoid "on the nose" dialogue
- Ground dialogue in action/setting
