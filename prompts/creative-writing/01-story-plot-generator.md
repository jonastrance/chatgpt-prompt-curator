# Story Plot Generator & Developer

## Category
Creative Writing

## Description
Generates compelling story plots with character arcs, conflict structures, and narrative frameworks for fiction writing.

## Prompt
```
Create a story plot for:

Genre: [e.g., Mystery, Romance, Sci-Fi, Fantasy, Thriller]
Length: [Short story, Novella, Novel]
Target Audience: [Age group and preferences]
Themes: [Major themes to explore]
Setting: [Time period and location]

Preferences:
- Tone: [e.g., Dark, Lighthearted, Serious, Humorous]
- POV: [First person, Third person limited, Multiple POVs]
- Ending: [Happy, Tragic, Ambiguous, Bittersweet]

Please develop:

1. PREMISE (One-sentence hook)

2. MAIN CHARACTERS (2-4 characters)
   - Protagonist: background, motivation, flaw
   - Antagonist: motivation, methods
   - Supporting characters

3. THREE-ACT STRUCTURE

   Act 1 - Setup (25%)
   - Opening scene
   - Inciting incident
   - Character introduction
   - World establishment
   
   Act 2 - Confrontation (50%)
   - Rising action
   - Midpoint twist
   - Complications
   - Character development
   - Subplot developments
   
   Act 3 - Resolution (25%)
   - Climax
   - Resolution
   - Character transformation
   - Thematic conclusion

4. KEY PLOT POINTS
   - Major turning points
   - Reveals and twists
   - Emotional beats

5. SUBPLOTS
   - Secondary storylines
   - How they weave into main plot

6. THEMES & SYMBOLISM
   - Central themes
   - Symbolic elements
```

## Usage Guide
1. Choose your genre and audience
2. Define core themes you want to explore
3. Develop characters using the framework
4. Outline each act in detail
5. Add your unique voice and style
6. Expand plot points into scenes
7. Maintain character consistency

## Example Output
A complete story structure with characters, three-act breakdown, plot points, and thematic elements ready to expand into a full narrative.

## Tips
- Start with a strong hook
- Create flawed, relatable characters
- Build tension progressively
- Plant setups for payoffs
- Maintain thematic consistency
- Leave room for character agency
- Revise and refine the outline
- Stay flexible as you write
