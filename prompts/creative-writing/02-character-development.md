# Character Development Profile

## Category
Creative Writing

## Description
Creates deep, multi-dimensional character profiles with backgrounds, motivations, conflicts, and development arcs for compelling storytelling.

## Prompt
```
Create a comprehensive character profile for:

Character Role: [Protagonist, Antagonist, Supporting]
Story Genre: [Genre of your story]
Character Archetype: [e.g., Hero, Mentor, Rebel, Caregiver]

Basic Parameters:
- Age range: [e.g., 20s, 40s, teenager]
- Setting: [Time period and location]
- Importance: [Main character, secondary, minor]

Please develop:

1. BASIC INFORMATION
   - Full name and nickname
   - Age, gender, physical description
   - Voice and mannerisms
   - First impression they make

2. BACKGROUND
   - Family and upbringing
   - Education and formative experiences
   - Key life events that shaped them
   - Current life situation

3. PERSONALITY
   - Core personality traits (5-7)
   - Strengths
   - Flaws and weaknesses
   - Fears and insecurities
   - Values and beliefs
   - Quirks and habits

4. MOTIVATION & GOALS
   - External goal (what they want)
   - Internal need (what they need)
   - What drives them
   - What they're running from

5. RELATIONSHIPS
   - Key relationships
   - How they interact with others
   - Trust and intimacy patterns
   - Conflicts with other characters

6. CHARACTER ARC
   - Starting point (who they are at beginning)
   - Transformation needed
   - Key moments of growth
   - Ending point (who they become)

7. VOICE & DIALOGUE
   - Speech patterns
   - Vocabulary level
   - Typical phrases
   - Internal thought style

8. CONFLICT
   - Internal conflicts
   - External conflicts
   - How they deal with adversity
```

## Usage Guide
1. Start with the basic concept
2. Build outward from core motivation
3. Create contradictions for depth
4. Connect background to current behavior
5. Plan character growth arc
6. Test character in different scenarios
7. Refine as you write

## Example Output
A detailed character profile with psychological depth, clear motivations, relationship dynamics, and transformation arc.

## Tips
- Give characters clear wants vs. needs
- Create believable flaws
- Root behavior in background
- Show don't tell personality
- Make choices reveal character
- Allow characters to surprise you
- Keep character bible for consistency
- Let secondary characters be distinct
