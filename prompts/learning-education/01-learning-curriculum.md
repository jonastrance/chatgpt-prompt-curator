# Personal Learning Curriculum Designer

## Category
Learning & Education

## Description
Creates customized learning paths and curricula for mastering new skills or subjects, with structured progression and resource recommendations.

## Prompt
```
Design a personalized learning curriculum for:

Skill/Subject: [What you want to learn]
Current Level: [Beginner, Intermediate, Advanced]
Time Commitment: [e.g., 5 hours/week, 10 hours/week]
Learning Duration: [e.g., 3 months, 6 months, 1 year]
Learning Style: [e.g., Visual, Hands-on, Reading, Video-based]
Goal: [What you want to achieve]

Please create:

1. CURRICULUM STRUCTURE
   - Foundation phase (weeks 1-X)
   - Intermediate phase (weeks X-Y)
   - Advanced phase (weeks Y-Z)

2. FOR EACH PHASE:
   - Learning objectives
   - Topics to cover
   - Recommended resources (free and paid)
   - Practice projects
   - Assessments/milestones

3. WEEKLY BREAKDOWN
   - Study schedule
   - Time allocation per activity
   - Practical exercises

4. RESOURCES
   - Books
   - Online courses
   - Video tutorials
   - Practice platforms
   - Communities to join

5. SUCCESS METRICS
   - How to measure progress
   - Project milestones
   - Skills checklist
```

## Usage Guide
1. Be clear about your starting point
2. Set realistic time commitments
3. Follow the curriculum sequentially
4. Complete practice projects
5. Join relevant communities
6. Track progress weekly
7. Adjust pace as needed

## Example Output
A comprehensive learning curriculum with phased approach, weekly schedules, curated resources, and practical projects to master the skill.

## Tips
- Start with fundamentals, don't skip ahead
- Practice daily, even if just 30 minutes
- Build projects to apply knowledge
- Teach others to reinforce learning
- Join study groups for accountability
- Review and revise regularly
- Celebrate small wins
