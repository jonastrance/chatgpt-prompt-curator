# Social Media Content Calendar

## Category
Content Creation

## Description
Generates a strategic social media content calendar with diverse post types, optimal posting times, and engagement strategies.

## Prompt
```
Create a 30-day social media content calendar for:

Platform(s): [e.g., LinkedIn, Twitter, Instagram]
Brand/Niche: [Your industry or focus]
Target Audience: [Describe your audience]
Posting Frequency: [e.g., Daily, 3x per week]

Content Goals:
- [e.g., Increase engagement]
- [e.g., Drive traffic to website]
- [e.g., Build thought leadership]

Please include:
- Mix of content types (educational, promotional, engaging, user-generated)
- Suggested hashtags
- Best posting times
- Content themes for each week
- Call-to-action ideas
```

## Usage Guide
1. Define your platforms and objectives
2. Understand your target audience
3. Set realistic posting frequency
4. Review and customize suggested content
5. Use a scheduling tool to plan posts
6. Track performance and adjust

## Example Output
A structured 30-day calendar with daily post ideas, content types, hashtags, and optimal timing for maximum engagement.

## Tips
- Follow the 80/20 rule (80% value, 20% promotional)
- Engage with comments within first hour
- Repurpose top-performing content
- Use analytics to refine strategy
- Plan but stay flexible for trending topics
