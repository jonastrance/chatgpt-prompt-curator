# Blog Post Outline Generator

## Category
Content Creation

## Description
Creates comprehensive blog post outlines with SEO optimization, clear structure, and compelling sections that engage readers.

## Prompt
```
Create a detailed blog post outline for:

Topic: [Your blog post topic]
Target Keyword: [Primary SEO keyword]
Target Audience: [Who is this for]
Desired Length: [e.g., 1500-2000 words]
Goal: [e.g., Educate, Convert, Entertain]

Please include:
- SEO-optimized title options (3-5)
- Meta description
- Introduction hook
- Main sections with H2/H3 headers
- Key points to cover in each section
- Examples/case studies to include
- Call-to-action
- Conclusion summary

Make it engaging and valuable for [target audience].
```

## Usage Guide
1. Research your topic and keyword
2. Define your target audience clearly
3. Specify your content goal
4. Review the outline structure
5. Add your unique insights and examples
6. Write following the outline framework

## Example Output
A complete blog post outline with hierarchical structure, SEO elements, and specific content suggestions for each section.

## Tips
- Start with a compelling hook
- Use subheadings every 300 words
- Include actionable takeaways
- Add internal and external links
- End with a clear call-to-action
- Optimize for featured snippets
