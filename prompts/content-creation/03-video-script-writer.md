# Video Script Writer

## Category
Content Creation

## Description
Creates engaging video scripts with hooks, storytelling elements, and clear structure for YouTube, TikTok, or other video platforms.

## Prompt
```
Write a video script for:

Platform: [e.g., YouTube, TikTok, Instagram Reels]
Video Length: [e.g., 30 seconds, 5 minutes, 10 minutes]
Topic: [Your video topic]
Target Audience: [Viewer demographics]
Video Style: [e.g., Tutorial, Entertainment, Educational, Review]

Please include:
- Attention-grabbing hook (first 5 seconds)
- Introduction with value proposition
- Main content sections with timestamps
- Visual/B-roll suggestions
- Transitions between sections
- Engagement prompts (like, subscribe, comment)
- Strong closing and call-to-action

Tone: [e.g., Casual, Professional, Humorous, Inspirational]
```

## Usage Guide
1. Define your platform and constraints
2. Know your target audience preferences
3. Plan visual elements alongside script
4. Practice reading the script aloud
5. Time each section accurately
6. Include personality and authenticity

## Example Output
A complete video script with timing, hooks, visual cues, and engagement elements formatted for easy reading while recording.

## Tips
- Hook viewers in first 5 seconds
- Speak directly to the camera/audience
- Use pattern interrupts to maintain attention
- Include timestamps for editing reference
- Add text overlay suggestions
- Script engagement moments strategically
- Keep language conversational
