# Email Newsletter Copywriter

## Category
Content Creation

## Description
Crafts compelling email newsletters that drive opens, clicks, and conversions with proven copywriting techniques and engagement strategies.

## Prompt
```
Create an email newsletter for:

Newsletter Name: [Your newsletter name]
Audience: [Subscriber demographics and interests]
Main Topic: [This edition's focus]
Goal: [e.g., Drive traffic, Promote product, Share insights]

Please include:
- 5 subject line options (A/B test ready)
- Preview text that complements subject
- Personalized greeting
- Opening hook/story
- Main content sections (2-3 topics)
- Visual content suggestions
- Links to include
- Clear call-to-action
- P.S. with additional value or urgency

Tone: [e.g., Friendly, Professional, Witty]
Length: [e.g., Short and punchy, Medium depth, Long-form]
```

## Usage Guide
1. Segment your audience for relevance
2. Test different subject lines
3. Write conversationally
4. Include one primary CTA
5. Optimize for mobile reading
6. Track metrics and iterate

## Example Output
A complete newsletter with subject lines, body content, and strategic CTAs designed to maximize engagement and conversions.

## Tips
- Keep subject lines under 50 characters
- Use personalization tokens
- Write scannable content with headers
- Include social proof or testimonials
- Add a single, clear call-to-action
- Use storytelling to connect emotionally
- A/B test different elements
- Send consistently on same day/time
