# Quick Start Guide

## Getting Started in 5 Minutes

### 1. Choose a Prompt (1 min)

Browse [PROMPTS_INDEX.md](PROMPTS_INDEX.md) and select a prompt that matches your need.

**Example**: Let's use the Task Prioritizer Pro from the Productivity category.

### 2. Open the Prompt File (1 min)

Navigate to: `prompts/productivity/01-task-prioritizer.md`

### 3. Copy the Prompt Section (1 min)

Look for the section marked with triple backticks (```) under "## Prompt". Copy everything inside.

Example from Task Prioritizer:
```
I have the following tasks to complete. Please analyze them using the Eisenhower Matrix and categorize each as:
1. Urgent & Important (Do First)
2. Important but Not Urgent (Schedule)
3. Urgent but Not Important (Delegate)
4. Neither Urgent nor Important (Eliminate)

Also provide a recommended order and time estimate for each task.

My tasks:
[LIST YOUR TASKS HERE]

Additional context about my goals and deadlines:
[ADD CONTEXT]
```

### 4. Customize with Your Details (1 min)

Replace the placeholders (text in [BRACKETS]) with your specific information.

**Example**:
```
I have the following tasks to complete. Please analyze them using the Eisenhower Matrix and categorize each as:
1. Urgent & Important (Do First)
2. Important but Not Urgent (Schedule)
3. Urgent but Not Important (Delegate)
4. Neither Urgent nor Important (Eliminate)

Also provide a recommended order and time estimate for each task.

My tasks:
- Finish Q4 report for board meeting
- Respond to client emails
- Review team's code submissions
- Plan next sprint
- Update LinkedIn profile
- Research new project management tools
- Attend networking event
- Clean out inbox

Additional context about my goals and deadlines:
Board meeting is Friday (3 days away). Client emails are from yesterday. Sprint planning needs to be done this week. The rest are ongoing tasks with no hard deadlines.
```

### 5. Paste into ChatGPT (1 min)

1. Open ChatGPT (https://chat.openai.com)
2. Paste your customized prompt
3. Press Enter
4. Review the results

### Expected Output

ChatGPT will provide a structured response categorizing each task into the Eisenhower Matrix quadrants with recommendations.
